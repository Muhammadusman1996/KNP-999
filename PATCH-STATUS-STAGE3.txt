KNP-999 - Stage 3 targeted fixes

Fix 1: Removed the legacy /api/round/settle endpoint that accepted a client-supplied payout. Only the authenticated server engine can determine payout.

Fix 2: Made server round settlement atomic: stake is conditionally debited only if the authenticated user's balance is sufficient; server-computed payout is then credited and ledger/history are written in the same SQLite transaction. This prevents race-condition overspending and client-chosen payouts.

Additional targeted wiring: the 7up7down dice game now sends its LOW/SEVEN/HIGH prediction to the server engine so the server resolves the same selected bet type.

Checks: Node syntax checks pass for server/index.js and all 140 frontend engine modules, and server engine modules. Full Vite build/browser QA was not run because dependencies are not installed in this environment.

Known remaining scope: 140 titles still share 13 gameplay profiles; this package does not claim 140 fully unique independently authored games.
