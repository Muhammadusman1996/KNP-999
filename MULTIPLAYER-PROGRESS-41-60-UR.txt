KNP-999 — مرحلہ 41 تا 60

اس اپڈیٹ میں گیم #41 سے #60 تک کے 20 گیم ماڈیولز میں موجود Socket.IO لائیو روم کنکشن شامل کیا گیا ہے:
- گیم کھولنے پر اسی گیم کے روم میں کنکشن
- آن لائن کھلاڑیوں کی تعداد اور کھلاڑیوں کے عوامی نام/اسٹیٹس
- بیٹ منتخب کرنے اور کھیلنے کے دوران روم اسٹیٹس اپڈیٹ
- اسی گیم کی حالیہ پلیئر ایکٹیویٹی
- گیم ہوم یا لابی پر واپس آنے پر روم کنکشن بند

اہم حد:
یہ مرحلہ آن لائن روم پریزنس اور ایکٹیویٹی فیڈ فراہم کرتا ہے۔ یہ ابھی مشترکہ synchronized round، ایک ہی server-generated نتیجہ سب کھلاڑیوں کو settle کرنا، یا مکمل multiplayer match system نہیں ہے۔ موجودہ انفرادی گیم راؤنڈز server-authoritative virtual coin API سے resolve ہوتے ہیں۔

تصدیق:
- گیم #41–#60 کے 20 frontend engine files پر node --check کامیاب۔
- تمام 195 server engine modules پر smoke test کامیاب: 195/195 نے درست response shape دیا۔
- مکمل Vite production build نہیں چلایا گیا کیونکہ اس ماحول میں npm dependencies نصب نہیں ہیں۔
